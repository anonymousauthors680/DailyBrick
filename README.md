# DailyBrick project page

This is a static website for GitHub Pages. Upload the entire contents of this directory to the root of a GitHub repository, then set **Settings → Pages → Deploy from a branch → main / (root)**. No build step is needed.

The page starts the video automatically, muted and looping when the browser permits it. Native video controls are hidden. A tap-to-play button appears if autoplay is blocked. Mobile screens use a smaller 640 px video (about 3.9 MB); wider screens use the desktop version. The video poster is a lightweight JPEG. The original `dailybrick-poster.jpg` remains the teaser image under the title.

The abstract is based on `sections/0_abstract.tex` in the paper source. Spelling and grammar were corrected for the website without changing its claims. Before publishing, compare it with the submitted paper and update both together if the abstract changes.

All content needed by the page is in this directory. Google Fonts is optional; local fallback fonts are provided.
